# v1.5 addendum placement and What-If interpretation

Written 27 Sep 2026 by the v1.5 measurement owner, before any A2 scoring.

## Frozen comparison

For each separately labelled v1.5 roster addendum, the page's fixed hypothetical placement is calculated against the frozen official v1.5.0 base board only. For option A (official headline) and option B (secondary view), placement is `1 + count(base point score > addendum point score)`. An equal point score follows the existing base row. A1, A2 and fast-lane addendum rows do not rank against one another in these fixed placement fields.

These are point-estimate placements. They do not modify the official base order, G_med or base paired-bootstrap tie markers. Addendum rows show their own paired-bootstrap 95% intervals. The page makes no pairwise tie claim between an addendum row and a base row or another addendum row.

## Interactive What-If scenarios

The What-If Lab may show a scenario position among all measured, eligible base and addendum rows when settings change. It labels that as a What-If position. Addenda remain excluded from the frozen base G_med and official A/B orders. The hidden What-If source may include measured fast-lane rows as addenda when an authorized aggregate-only result and matching provenance are available; author-held or excluded rows remain out.
